# Moved to github.com/Justichuu/u

This was one half of the U device. The other half was built the same hour by a
different session that could not see this one. They are now in one place:

### → **[github.com/Justichuu/u](https://github.com/Justichuu/u)**

Everything that was here is there, plus the `u-device/1` protocol, the test
suite and the full provenance record.

Nothing about the device changed in the move. Same three faces, same four
functions, same tape:

```text
01u10u000u0u11110u1uu1
```

Same key, `66cce8d50854`, which is `sha256` of that tape. It still resolves to
the same names, now at [PROVENANCE.md](https://github.com/Justichuu/u/blob/main/PROVENANCE.md)
and [chuumind.com/u](https://chuumind.com/u).

That is the point of a fingerprint computed from behaviour rather than written
down. The repository moved. The device did not, so its name did not move either.

This copy is left standing rather than deleted, because a push is one way.
Clones and caches of it exist and deleting it here would not recall them. It is
a reflection, and it is labelled as one.
